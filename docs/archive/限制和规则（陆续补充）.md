# 天天打卡内容限制和规则

## 展示和录入限制

- 昵称限制5个字符。
- 全局累计坚持天数按存在有效打卡的自然日去重计算，展示上限为999天，超过显示“999+”。
- 任务最多支持10个任务同时进行。
- 任务名称限制20个字符。
- 完成目标奖励描述限制20个字符。
- 撤销/补卡说明内容限制100个字符，去除首尾空格后不能为空。
- 撒花动效先统一用动效素材文件里面的“Confetti”。
- 开发时字体统一使用阿里巴巴普惠体 2.0，字体包位于`/Users/guzeyang/Desktop/产品管理/阿里巴巴普惠体 2.0`，需要随PWA本地打包并加入离线缓存。
- 图标、图片等元素优先使用figma中的。

## 规则

- 本周展开为本月，通过上下滑动切换上个月或下个月。
- “连续坚持”为截至当前最近连续存在有效打卡的自然日数量；“坚持”为存在有效打卡的累计自然日数量，同一天多个任务只计1天。
- 首页“进步第N天”和分享卡“坚持N天”使用累计坚持天数；只有真实连续未中断时才使用“连续坚持”文案。
- 同一任务的同一里程碑最多计为一枚勋章；撤销后重新点亮只恢复原勋章，不重复增加累计获得次数。每个任务最多四枚勋章，当前10个进行中任务最多对应40枚里程碑勋章；归档后继续创建新任务，历史累计勋章允许超过40枚。
- 补卡与撤销使用相同的底部弹层结构，并在真正写入数据前进行二次确认。
- 家长确认奖励已兑现后任务归档结束，从今日任务移除；历史记录、勋章和分享能力继续保留。
- 最多同时进行10个任务，已归档任务不占用名额。
