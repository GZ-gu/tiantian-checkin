# 勋章与分享卡片视觉方向

> 视觉参考：本文件用于勋章和分享卡风格探索，不是业务规则来源。涉及打卡方式、目标天数、奖励触发和功能范围时，以 [天天打卡_V1.1_PRD.md](../天天打卡_V1.1_PRD.md) 为准。

## 1. 总体风格

这个产品的视觉应该介于“儿童友好”和“家长可信”之间。不能太幼稚，也不能像学校管理系统。

推荐关键词：

- 轻游戏化
- 明亮
- 有成就感
- 干净
- 可爱但不低龄
- 适合中小学生
- 适合发到家长微信群

不建议：

- 过度卡通
- 过度幼儿园风
- 大面积糖果色
- 复杂 3D 游戏 UI
- 排行榜压迫感
- 太像教育机构广告

## 2. 勋章风格

### 推荐方向

勋章建议采用“圆形徽章 + 中心图标 + 外圈进度”的结构，方便做灰色到彩色的填充动画。

基础结构：

- 外圈：表示目标周期，如 7 天、21 天、30 天
- 中心图标：表示任务类型，如书本、单词、铅笔、计算、运动鞋、音符
- 底部小飘带：显示勋章名称
- 星星或闪光：表示已点亮

### 灰色未完成态

未完成时：

- 主体为浅灰色
- 图标低饱和
- 外圈有空进度
- 文字显示“3/7”“5/21”

### 注水填充态

每打卡一次，勋章从底部向上填充彩色，就像水位上升。

视觉建议：

- 底部彩色区域逐步升高
- 已填充区域颜色更亮
- 未填充区域保留灰色
- 填充边缘可以有轻微波浪
- 完成当天出现小星星或光点

### 点亮完成态

完成后：

- 整枚勋章变彩色
- 外圈发光
- 中心图标清晰
- 飘带显示“已点亮”
- 可加 1-2 个小闪光装饰

## 3. 勋章主题建议

第一版可以先做 6 类通用勋章：

| 类型 | 图标方向 | 名称示例 |
|---|---|---|
| 背单词 | 字母 A / 单词卡 / 小书本 | 单词小勇士 |
| 阅读 | 打开的书 / 书签 | 阅读小达人 |
| 练字 | 铅笔 / 毛笔 / 田字格 | 练字小能手 |
| 口算 | 数字 / 算盘 / 闪电 | 口算小飞侠 |
| 运动 | 运动鞋 / 奖牌 / 跑道 | 活力小冠军 |
| 自定义 | 星星 / 旗帜 / 拼图 | 坚持小徽章 |

## 4. 配色建议

整体不要只用一种颜色。建议使用温暖、明亮、低压迫感的配色。

推荐颜色：

- 主色：活力蓝 `#3B82F6`
- 成就黄 `#FACC15`
- 成长绿 `#22C55E`
- 阅读紫 `#A78BFA`
- 暖橙 `#FB923C`
- 背景浅灰 `#F8FAFC`
- 文字深色 `#1F2937`

不同任务类型可以用不同点缀色：

- 背单词：蓝色
- 阅读：紫色
- 练字：橙色
- 口算：绿色
- 运动：黄色
- 自定义：青色

## 5. 分享卡片风格

分享卡片是这个产品的传播核心，必须比微信群文字接龙更有展示欲。

### 推荐比例

适合微信分享和朋友圈预览：

- 竖版：1080 x 1440
- 方版：1080 x 1080

第一版建议优先做竖版，更适合展示孩子成就。

### 卡片结构

建议从上到下：

1. 顶部标题
   - “今天也打卡啦”
   - “我的阅读勋章进度”

2. 孩子信息
   - 昵称
   - 年级可选
   - 连续打卡天数

3. 主视觉
   - 当前勋章
   - 注水进度
   - 例如 5/7

4. 今日任务
   - 今天完成：阅读 15 分钟
   - 打卡方式：照片 / 文字 / 勾选

5. 本周进度
   - 7 个小圆点表示本周完成情况
   - 已完成为彩色，未完成为灰色

6. 激励文案
   - “小小坚持，正在变厉害”
   - “这枚勋章快点亮了”

7. 底部品牌
   - 打卡了吗
   - 小程序码位置预留

## 6. 分享卡片视觉气质

推荐气质：

- 像一张儿童成就证书
- 像游戏任务结算页
- 像学习小奖状
- 但保持干净，不要太花

可以参考的视觉元素：

- 奖牌
- 小旗帜
- 星星
- 彩带
- 进度环
- 贴纸
- 书本和铅笔
- 小奖状边框

不要使用：

- 大面积金色土豪风
- 复杂背景图
- 过多角色 IP
- 强烈排名符号
- “超过 99% 同学”这类焦虑文案

## 8. 线框图绘制建议

你画线框图时，优先画这 4 张：

1. 家长发布任务页
   - 任务名称
   - 目标天数
   - 打卡方式
   - 奖励建议

2. 孩子今日打卡页
   - 今日任务
   - 上传打卡
   - 当前勋章进度

3. 勋章点亮页
   - 灰色勋章
   - 注水进度
   - 完成后彩色状态

4. 微信分享卡片
   - 孩子昵称
   - 连续天数
   - 勋章
   - 本周进度
   - 小程序码预留

## 9. 最重要的视觉原则

这个产品的视觉核心不是“可爱”，而是“孩子愿意晒，家长愿意转发”。

所以每个勋章和分享卡都要回答：

- 孩子看到后，会不会想点亮？
- 家长看到后，会不会愿意发群？
- 群里其他家长看到后，会不会觉得“这个挺有意思”？
