# 天天打卡 1.2.19 问题修复验收

## 问题、根因与修改位置

| 问题 | 根因 | 修改位置 |
| --- | --- | --- |
| 弹窗小狮子出现白色方底 | `modal-lion.png` 的 Alpha 通道全部为 255，白底已写入图片 | `assets/figma/modal-lion.png`，改用 Figma 节点 `192:3242` 的原始透明图片 |
| 补卡二次确认放大、裁切 | 原因输入框为 14px，iPhone Safari 聚焦时自动缩放页面，提交后缩放未恢复 | `styles.css` 的 `.reason-control`、`.bottom-sheet`、`.confirm-message` |
| 打卡确认提示换行 | 提示容器横向内边距过大，小屏可用宽度不足 | `styles.css` 的 `.sheet-notice` 和 360px 响应式规则 |
| 手机出现双状态栏 | 页面仍渲染一套模拟系统状态栏 | `app.js` 移除状态栏渲染，`styles.css` 同步收回 50px 顶部空间 |
| 成功页勋章和圆环错位 | 360px 规则单独放大勋章但保留旧偏移 | `styles.css` 的 `.success-medal-ring`、`.success-medal-core`、`.success-inner-ring`、`.success-medal` |
