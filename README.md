# 天天打卡

面向家庭的轻量学习打卡 PWA。家长创建自定义任务，孩子每天完成一次直接打卡，通过勋章逐步注水上色、里程碑庆祝和家庭奖励回应，把坚持变成看得见的成就。

## 产品定位

第一版先验证一件事：孩子是否会因为勋章成长反馈而愿意第二天继续打开。

核心闭环：

`家长发布任务 -> 孩子直接打卡 -> 勋章注水 -> 点亮勋章 -> 分享/家长回应 -> 第二天继续`

## MVP 范围

- 三个主流程：天天打卡、发布任务、我的勋章
- 自定义任务名称、目标天数和奖励建议
- 每项任务每天只能直接打卡一次
- 点击打卡后二次确认，记录打卡时间，并允许短时间撤销
- 7/14/21/30 天阶段勋章
- 灰色勋章从下向上逐步变彩色
- 普通打卡轻反馈，勋章点亮时使用更强庆祝
- 数据优先保存在本机，后续补充导入和导出
- 支持离线 PWA，兼容 iPhone Safari 与 Android Chrome

第一版不包含：账号系统、家庭成员绑定、照片/文字打卡、AI 批改、排行榜、课程售卖和付费系统。

## 设计原则

- 儿童友好，但让家长感到可信
- 黄色表达品牌和成就，不让所有元素都像主按钮
- 任务与打卡优先于 IP、奖励和分享
- 使用 Figma Variables、Components、Variants、Frame 和 Auto Layout
- 新增高保真页面统一使用可编辑的 Noto Sans SC
